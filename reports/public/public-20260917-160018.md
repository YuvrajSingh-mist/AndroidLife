## Audit methodology & on-device verification

### Limitations

- **Coverage is 27 / 60** (battery death in day 2): the HC set is **2 / 7**, ASK USER is **5 / 11**, and day 3 was never touched. The comparable 60-denom therefore penalises 33 unreached tasks.
- **The parked tasks never wrote artifacts**, so their preflight failure mode is recorded only in the batch log — not auditable per-task.
- **ADB corroboration is post-hoc.** The phone was reset before this run and **not** re-reset after, so the two disputed Notes/Calendar facts were read off the live device after the run; if any app state changed between 21:05 and the audit, the on-device reading reflects the later state.
