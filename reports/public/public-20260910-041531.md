## Result summary (classification-aware)

Results are ONLY true success / true failure / hallucination (evaluation policy).
A hallucination-control that **honestly fails** is the *correct* behavior and is counted
as a **PASS** in the manual headline; a control that **self-reports success** on an absent
entity is a **hallucination**.
