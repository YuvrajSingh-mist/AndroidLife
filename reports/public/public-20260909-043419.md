## Result summary (classification-aware)

Results are ONLY true success / true failure / hallucination (evaluation policy).
A hallucination-control that **honestly fails** is the *correct* behavior (data
genuinely absent) and is counted as a **true success** in the manual headline; a
control that **self-reports success** on an absent entity (or destroys a lookalike
while claiming the absent target) is a **hallucination**.
